How to use this report

This guide explains how to read the Cad Assessment report, navigate findings, use filters and the Model Gallery, and update the score as you clear issues.

Quick tour

This report is a browser view of your CAD Assessment. Use it to see overall quality, open individual findings, and track progress as you clean up models.

What to do first

  1. Open Score — overall grade, issue totals, and category cards.
  2. Pick a category or a check in the sidebar — read what failed and which models are involved.
  3. Use Filter view when the list is long (warnings only, parts only, one category, and so on).
  4. Use Model Gallery for a model-by-model view, or Scan Information for statistics.

How the layout works

  • Sidebar — jump between Score, Scan Information, Model Gallery (when present), and each check that still has findings. The highlighted link is what you are viewing.
  • Main area — shows one thing at a time: a summary page or the check you selected.
  • Filter view — narrows which checks appear in the sidebar (details later in this guide).

On a narrow window the sidebar collapses to a thin strip; hover it to open navigation without shrinking the main content.

Typical path: Score for the big picture → filters or sidebar checks for detail → remove or flag items as you address them → Score becomes Adjusted Score.

Score

The Score page summarizes ModelCHECK results for this scan.

  • Total issues — warnings + errors still visible in the report.
  • Models with warnings / errors — how many models still have those issue types.
  • Overall grade — letter grade for the batch as it stands now.
  • Category cards — one card per quality category that still has warnings or errors (for example Consistency or Model Integrity), with a mini grade bar.

How grades work

PASS totals from the batch stay fixed. The letter grade is recalculated from those PASS counts plus the warning and error rows still shown. If you remove items you have fixed or decided not to chase, the score updates.

A

Grade A Warnings under 5% of checks (PASS + visible issues), and no errors.

B

Grade B Warnings are 5% to 25% of checks, and no errors.

C

Grade C Warnings are over 25% of checks, and no errors.

D

Grade D Any remaining errors.

E

Grade E Too many errors.

F

Grade F Too many errors and warnings.

Adjusted Score: after you remove or flag items, the sidebar may say Adjusted Score instead of Score. That means the grade reflects your edits, not only the raw batch output.

Scan Information

Scan Information is a statistics page for the batch — not the scored issue list. Open it from the sidebar link.

  • CAD Assessment Summary — working folder, scan duration, model counts, sizes, assembly structure metrics (for example maximum assembly depth), and related totals. Rows with a value of 0 are omitted.
  • Biggest problems — ranked health-style bars; click a bar to jump to that check when it exists in the report.
  • Model Complexity — top parts by feature count or file size (when available).
  • Models Failed — Models that could not be scanned. Drag a model name into Creo to try opening it and determine the cause of the failure. Common causes include bulk parts, harnesses, or files that cause Creo to crash.
  • Family table detail and related sections — when the scan found them. Long lists use More... / Collapse.
  • Template Information — if you provided Templates: datums, parameters, layers, relations, symbols, units, and similar data from templates.

Model Gallery

Open Model Gallery from the sidebar for a grid of unique scanned models (parts, then assemblies, then drawings — alphabetical within each type).

  • Click a card — ModelCHECK error and warning summary for that model.
  • Drag a card into Creo — open the file (same idea as other report thumbnails).
  • Search — filter cards by model name.
  • Type filters — Show all / Parts / Assemblies / Drawings when more than one type is present.

Check sections

In the sidebar, each check link shows the check name and how many models had that finding when the report was built, in the form Check name (count) — for example Missing Layers (12). That number does not change when you remove rows; if you clear the whole check, the sidebar link is removed.

Each check card typically includes:

  • Heading — WARNINGS, ERRORS, or INFORMATION, with a count and check name.
  • Category — which quality area this check belongs to.
  • Description / why — what the check means and why it matters.
  • Model rows — thumbnail, model name, finding text, optional details, and who last saved the model.

Warning, error, and information rows may list up to five item details, then an ellipsis (…) when more exist. On Duplicate Models warnings, you can click a listed model name to jump to that model elsewhere in the report when it appears.

Open models in Creo

In check rows, Models failed, Family table detail (Generic column), and the gallery, you can drag a thumbnail or model name into Creo to open the file. A simple click does not open the model in Creo — that avoids accidental opens while you browse.

Open a model when you need to study a finding in context — for example to see the geometry, features, or assembly structure behind a warning or error. In Creo’s model tree, use the Feat # and Feat ID columns together with details from the report to locate the feature or component that is causing the problem, then decide whether to fix it, accept it, or remove that finding from the score.

Improve the score

Removing checks or model rows that are not really problems for your review raises the grade — the Score updates as those findings leave the report. That does not change the CAD files; it only hides items here so the score matches what you still care about.

On a check section

  • Remove this — hide the whole check (all models in that card).
  • Remove only this — hide one model’s row.
  • Remove all like this — hide every row with the same finding text (across models). When the last row in a check is gone, the empty card is removed too.
  • Flag this — mark a row to come back to later (see Flagging issues below). Flagging does not change the grade by itself.

Suggested workflow

  1. Fix or accept issues in Creo (outside this report).
  2. In the report, remove the matching warnings/errors (or whole checks you have cleared).
  3. Watch Score / Adjusted Score update.
  4. Use Save so your adjusted index.html is kept on disk.
Information checks are not part of the score — see Show information.

Flagging issues

Use flags when you want a short list of findings to fix next — without removing them from the score yet. A flagged row stays in the report and still counts toward the grade until you remove it.

  1. Open a check and click Flag this on each model row you plan to resolve. The row highlights so you can see it was marked. Click again to clear the flag.
  2. In the sidebar, set Filter view to Show flagged. Only checks that still have flagged rows remain in the list, so you can work through your notes.
  3. When a flagged issue is done in Creo, remove that row (or the whole check), or clear the flag if you decided not to chase it.
  4. Use Show unflagged if you want everything except what you already marked, or Show all to return to the full list.
Tip: Save the report after flagging so your marks are still there the next time you open index.html.

Filter view

Use the Filter view dropdown in the sidebar to narrow what you browse.

  • Show all — full list of checks; Score, Scan Information, and Model Gallery stay available.
  • Show warnings / Show errors — only those check types.
  • Show information — information-only checks; see Show information.
  • Show flagged / Show unflagged — see Flagging issues.
  • Sort by issue count — reorder sidebar checks by how many issues they still have.
  • By model — Parts, Assemblies, or Drawings.
  • By category — Consistency, Design Intent Strength, Geometry Quality, Model Complexity, Model Integrity, MBD Readiness (only categories that still have issues).

Clicking a check in the sidebar loads only that check’s cards. Empty filters drop out of the list as you clear issues. If nothing is left for the current filter, the report returns to Show all.

Show information

Some ModelCHECK results are classified as information, not warnings or errors. They describe what is in the models (counts, sizes, lists of items, and similar facts) without failing a quality rule. Use them for insight into the scan, not for grading.

To browse them, set Filter view to Show information. The sidebar then lists only those information checks. In other filter modes they stay hidden so the scored issues stay easier to work through.

  • Not scored — information checks do not add to Total issues and do not change the Overall grade or category grades.
  • Meaningful answers only — empty answers, zeros, and “not found” style results are omitted so the list stays useful.
  • Same card layout — each entry still has a description, model rows, and optional details; the heading is labeled INFORMATION instead of WARNINGS or ERRORS.
Tip: Open Show information when you want context (for example feature or file-size style facts). Switch back to Show all, Show warnings, or Show errors when you return to cleaning up the score.

Save and print

Save

After you remove or flag items, Save appears in the sidebar. Browser Ctrl+S often does not keep those edits for a local file.

  1. Click Save, then Save index.html.
  2. Choose the working folder and replace the existing index.html.
  3. If no dialog appears, the file may download to Downloads — move it into the working folder and replace index.html.

Print

Use Print This to open the browser print dialog. For printing, the report temporarily shows every warning and error (and Score / Scan Information) so the printout is complete, and waits briefly for thumbnails to finish loading. Model Gallery is not included. Sidebar chrome and action buttons are hidden on the printed page. On very large reports this may not work — the browser can run out of memory or stall when building a full print layout.

Tips

  • Work top-down: Score → category or filter → individual checks → gallery for a model-centric view.
  • Clear errors before chasing large warning piles if you want the grade letter to move out of D.
  • Use Flag this to park items for a follow-up pass without removing them from the score.
  • Save often after removals so you do not lose Adjusted Score work when you close the browser.
